# La noche de Pérez — prototipo

Prototipo aislado de navegación mobile-first. No reemplaza todavía /modo-padres/.

## Vista previa
Cuando GitHub Pages termine de publicar la rama principal:
https://jbustoscasta.github.io/villa-perez-premium/la-noche-de-perez/

## Qué permite revisar
- Inicio vertical a pantalla completa.
- Acceso a destino, vídeo, pruebas, carta y cofre.
- Flujo guiado con vuelta atrás y accesos directos.
- Pantalla de referencia para selfie y ventana.
- Carta con vista previa y guardado local de prueba.
- Enlaces a los módulos existentes de vídeo, huellas y Cámara Mágica.

## Qué es solo maqueta
- El mapa es un esquema visual; no calcula rutas.
- Selfie y ventana permiten revisar el encuadre, pero todavía no componen/exportan la imagen final.
- La carta se guarda como dato de demostración en localStorage.
- El Cofre no sincroniza todavía los resultados de los editores.
- El modo niño enlaza a la Cámara Mágica actual, cuyo repositorio todavía exige un vídeo.

Ver docs/la-noche-de-perez-arquitectura.md para el modelo objetivo, las limitaciones detectadas y el plan por fases.
